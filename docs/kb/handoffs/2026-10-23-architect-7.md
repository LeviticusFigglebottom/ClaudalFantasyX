## Done
M1-ARC-07: the camera's contract with the cutscene sequencer, from the review-sweep-C findings on M1-ARC-05.
- **`release()` honours `force_hard_cut`.** The volume it returns to (the winner, or the remembered return volume) cuts if it is marked `force_hard_cut`, even when `release` is given an explicit `blend_sec`. A shot's own soft `hard_cut` is still overridden, so a hand-back blends by default.
- **`blend_finished` fires for every transition that lands.** That includes cuts (at the end of the `update()` that applies them) and no-move `play_shot`/`release` calls (at the end of the next `update()`). It is never emitted synchronously, so `play_shot(...)` then `await blend_finished` can't miss it or hang on `blend=0`. A cut onto a shot that is still blending in ends the blend and lands once. A transition that is replaced before it lands doesn't fire. A new `is_settled()` returns true when no blend is running and no emission is owed.
- **Cue schema** (`game/data/dialogue/cues.json`):
  - `@camera` gains `ease=` (an enum over the new `camera_eases` set).
  - `reserved.camera.release` is `{doc, kwargs: [blend, ease]}`.
  - `tools/dlgc.py` `check_cue` limits a reserved command that declares `kwargs` to those keys. The change is confined to cue/arg checking: `@camera release grade=…` gives "`@camera release: unknown key 'grade='`".
  - `tools/validate_data.py` checks the shape of reserved values. Its new `camera_ease_errors` check fails when `camera_eases` drifts from the eases in `field_camera.json`.
- `DialogueStep.CAMERA_RELEASE` and `is_camera_release()` added. `test_dialogue_vs_scenes` no longer treats `release` as a haluna.md shot id.
- **Docs.** The contract is in `docs/kb/tech/field_camera.md` (release, "Knowing a move landed", the `@camera`/`@camera release` mappings). The cue table and the `reserved` note are in `docs/kb/tech/dialogue_format.md`.
- **Tests.**
  - `tests/unit/test_camera_director.gd` has 6 new tests: force_hard_cut on release, cut lands on the next update, volume cut lands, no-move settles, cut onto a blending shot lands once, superseded cut is silent.
  - `tests/unit/test_dialogue_runner.gd` has 1 new test.
  - `tools/tests/test_dlgc.py` has a new `CameraCueTests` class (4 tests) and one new reserved-shape test.
