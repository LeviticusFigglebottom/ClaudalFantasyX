## Done
- **Save v6.** `SAVE_VERSION = 6`. `_migrate_v5_to_v6` adds `swell: {unlocked: [], progress: {}}`; its literal is frozen, and it chains after v4 → v5.
- **Gauges and modes** ride in `party_vitals` entries. `swell` is stored only when above 0, and `swell_mode` only when it differs from swell.json's default.
  - Out: `Game.record_party`, after a victory or an escape.
  - In: `GameStateData.apply_vitals_to`, which clamps the gauge to 0..100.
  - A defeat writes nothing. `full_heal` (a shrine) keeps both keys, as decided here.
- **Party record.** `GameStateData.swell` holds the unlocked modes and unlock counts.
  - The new `EventBus.battle_swell_returned` signal carries it to `Game.record_swell`, which refuses while swell.json is broken.
  - `BattleSwellCarry.attach` loads it before `BattleSwell.attach`.
- **SaveShape** checks `_swell` and the two new vitals keys.
- **DataHealth** gains an eighth check, `swell` (`BattleSwell.config_problem`). Tests inject `swell_config` and set `swell_loaded`.
