## Done
- **M1-RND-19** (review: character). `CharacterShaderTiers.apply_to_tree` is now **copy-on-swap**:
  - A material that needs a new shader is duplicated first, unless it is a copy this function made for the same root. Ownership is the `hymn_tier_owner` meta, holding `[root id, copy's own id]`, so a duplicate of an owned copy is not owned.
  - The copy goes into the slot: `material_override`, the surface override, or (for a mesh's own surface material) the surface override slot. Shared `.tres` files, import-time overrides and meshes are never mutated.
  - Slots under one root that shared a source share one copy. A repeat call on the same root swaps in place. Materials already at the tier get no copy.
  - `apply_tier` still mutates in place, and its doc says so. New public helpers: `target_shader_path` and `owns`.
