  - It waits for nodes (`wait_for_node`: freed, or `is_running()` false) and for conditions (`wait_until`).

## API for M1-UI-11 (m2-slice): a preset change behind a card
```gdscript
var card := BootCard.cover(get_tree().root, SceneRouter.FADE_SEC, SceneRouter.FADE_SEC)  # fade in, lift
card.covered.connect(func() -> void:
	GraphicsRuntime.select_preset(id, get_viewport())          # spawns the resident warm-up
	card.wait_for_node(GraphicsRuntime.current_warm_up())
	card.arm())
card.opened.connect(func(stats: Dictionary) -> void:
	# give the menu its input back here
	SceneRouter.measure_reveal(scene_file_path, card.is_lifted, stats))
card.revealed.connect(card.queue_free)
```
- The card stops the mouse. Block keys yourself (for example with `set_process_unhandled_input(false)`), as boot does for the title.
- The `boot_title` shot never sees a card.
