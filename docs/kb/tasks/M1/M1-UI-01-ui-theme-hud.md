## Notes
Delivered (how it works: `docs/kb/tech/ui.md`):
- **Theme:** `game/ui/theme/hymn_theme.tres`, generated by `HymnThemeBuilder` from `game/data/ui/theme.json` and `docs/kb/art/palette.json`. A drift test guards it. Tide-notch panels (`TideNotchStyleBox`), chamfered focus and cursor frames, gauges, scrollbars, and 16 type variations. Palette roles are theme colors of type `Hymn`. Shaders: `game/ui/shaders/lamp_mote.gdshader` and `scrim.gdshader`.
- **Fonts:** Source Sans 3 (Regular, Medium, Semibold, Bold, It) and EB Garamond (Regular, Italic), 2.3 MB, from Ubuntu packages. Cormorant Garamond isn't packaged where we can reach it, so we use art's documented fallback serif.
- **HUD** (`game/ui/battle/`, layout in `game/data/ui/battle_hud.json`): TurnTimeline (16 slots; shape-coded sides; ghost, ▲/▼, skipped and target marks; animated previews), PartyPanel (HP/MP, hatched low HP, vector status glyphs), CommandMenu (keyboard, controller and mouse), TargetCursor, DamageNumber, BattleResultPanel.
- Tests: `tests/unit/test_ui_theme.gd`, `test_ui_hud.gd`, `test_ui_timeline.gd`. Shots: `battle_hud_preview`, `battle_swap_menu`, `battle_victory`.
- **Deviations for review** (listed in tech/ui.md): the timeline is 208 px wide instead of 168, rank labels are 22 px instead of 20, preview arrows mark only the actor and its targets, and the font shadow is an outline. Not built: background blur, colorblind swap, reduced motion, text size, Swell gauge.
- For the Lead: `project.godot` could set `gui/theme/custom` to the theme. It isn't set yet; each UI root assigns it.
