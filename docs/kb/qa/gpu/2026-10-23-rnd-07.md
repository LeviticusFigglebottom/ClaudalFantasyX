## Scene-entry hitch on a real GPU (`tools/gpu_bench/run_prewarm.sh`)

**Method.** The worst frame among the first 180 frames after a scene is added (it's loaded from disk beforehand), High preset, 1920×1080. A **cold** run first deletes this project's Godot caches (`user://shader_cache`, `user://vulkan`); AMD's own driver cache stays warm. **Prewarm** runs `ShaderPrewarm` for the scene before adding it. Data: [`2026-10-23-rnd-07-prewarm.csv`](2026-10-23-rnd-07-prewarm.csv), and the run before `scene_materials` existed: [`…-registry-only.csv`](2026-10-23-rnd-07-prewarm-registry-only.csv).

| Scene | Cold, no prewarm | **Cold, prewarm** | Warm, no prewarm | **Warm, prewarm** | Prewarm's own worst frame |
|---|---:|---:|---:|---:|---:|
| water_test | 786 ms | **8.0 ms** | 496 ms | **6.8 ms** | 142–144 ms |
| vegetation_test | 776 ms | **20.4 ms** | 511 ms | **15.7 ms** | 121–128 ms |
| undertow_test | 965 ms | **24.9 ms** | 633 ms | **24.3 ms** | 147–150 ms |
| glimmer_dusk | 555 ms | **13.9 ms** | 273 ms | **12.7 ms** | 131–133 ms |
| haluna_mood | 1471 ms | **39.4 ms** | 1082 ms | **35.2 ms** | 147–150 ms |

- **Without prewarm, every scene's first frame breaks the SPEC §4.2 50 ms budget, even with warm caches** (273–1082 ms). The pipeline cache doesn't remove first-use costs: pipeline creation and resource uploads.
- **With prewarm, every scene enters at ≤ 39 ms**, cold or warm. Before `scene_materials` (registry only), `glimmer_dusk` still took 142 ms, because its inline StandardMaterial3Ds weren't registered. Harvesting the scene's own materials fixed it.
- **Prewarm's own worst frame is 121–150 ms.** It falls during the transition, behind the fade (`ShaderPrewarm` logs it as over budget). Follow-up if the transition itself must hold 50 ms: spread the stage over several frames (a materials-per-frame budget).

## Low-preset AA on alpha-tested foliage (`tools/gpu_bench/aa_shimmer.tscn`)

**Method.** `vegetation_test` with its wind frozen and the camera yawing about 0.2 px per frame, so any frame-to-frame change is temporal aliasing. Low preset at 1080p with only `aa` overridden; 120 warm-up frames, then 30 frames. The flicker index (`aa_shimmer.py`) is the mean consecutive-frame difference in linear light over the busy (top 10 % contrast, foliage-edge) pixels.

| `aa` at Low | GPU median | Flicker, whole frame | **Flicker, edge pixels** |
|---|---:|---:|---:|
| none | 0.529 ms | 0.01226 | 0.03938 |
| FXAA (old Low) | 0.512 ms | 0.01087 | 0.03536 |
| SMAA | 0.562 ms | 0.01201 | 0.04033 |
| **TAA (new Low)** | 0.627 ms | 0.00451 | **0.01359** |

FXAA removes only 10 % of the foliage shimmer, and SMAA none: both are spatial and can't resolve cut-out edges that change frame to frame. TAA cuts it **2.9×** for +0.12 ms here, about 0.5–0.6 ms on a GTX 1060, well inside Low's headroom (below). Low's FSR1 upscaler is spatial, so it composes with TAA. To watch: TAA ghosting at 30 fps on minimum-tier cards.
