## Day-shot glow dither (`undertow_day_ch08`, held storm, 120 settle frames)

High-frequency RMS (luminance minus its 3×3 mean) over the cyan glow pixels (about 4 % of the frame):

| Configuration | Glow dither |
|---|---:|
| Capture rig: FXAA, static pattern (the lavapipe baseline setup) | 0.0299 |
| High (FSR2 at 0.77), jitter frozen | 0.0404 |
| High (FSR2), rotating jitter | 0.0259 (−36 %) |
| High (FSR2), rotating plus per-frame IGN pixel shift (tried, reverted) | 0.0296 |
| Ultra (native TAA), jitter frozen | 0.0461 |
| **Ultra (native TAA), rotating jitter** | **0.0071 (−85 %)** |

- **Under native TAA (Medium and Ultra) the dither integrates**: the crop is smooth glow.
- **Under FSR2 (High) it only partly integrates.** Godot 4.6 provides no FSR2 reactive mask for transparent materials, so FSR2 accumulates the storm body conservatively.
- **Mitigation for storm close-ups on High:** cutscenes can switch to TAA with FSR1 or bilinear scaling (a settings override behind the cut).
- **Rejected:** Jimenez's per-frame IGN pixel shift made FSR2 *worse*, presumably because history clamping rejects more when successive frames differ spatially.
- **FXAA captures keep a static pattern by design.**
